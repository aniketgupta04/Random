# Date Invitation Website

## Run it
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Double-click `index.html`, or use the Live Server extension.

## Customize
- Replace photo placeholders in `index.html` with your own `<img>` tags.
- The Bubu Dudu images are referenced from `assets/bubu-dudu.jpg`, `assets/bubu-dudu-pink.jpg`, and `assets/bubu-dudu-seaside.jpg`.
- The scrapbook photos are referenced from `assets/memory-gudda.jpg`, `assets/memory-me.jpg`, and `assets/memory-us.jpg`.
- The music is referenced from `assets/khat.mp3`.
- Edit the letter text directly in `index.html`.
